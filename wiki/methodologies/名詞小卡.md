# 名詞小卡：股市 AI 研究的基本術語

> 給不熟悉金融的讀者。標「出處」的定義取自本 wiki 已收錄的論文；其餘為一般教科書定義，不屬於任何單篇論文的實證結論。

| 術語 | 白話定義 | 出處 |
| :--- | :--- | :--- |
| **夏普值 (Sharpe ratio)** | 超額報酬除以報酬的標準差，也就是「每承擔一單位風險，換到多少報酬」。Fischer & Krauss 把它形容為金融上的訊噪比。 | [[2018_EJOR_Fischer_Krauss_Deep_Learning_with_LSTM_Networks_for_Financial_Market_Predictions]] |
| **超額報酬／Alpha** | 扣掉市場整體漲跌或常見風險因子能解釋的部分之後，額外多賺（或少賺）的報酬。 | 一般定義 |
| **放空** | 先借股票來賣出，等股價下跌再買回還給出借人，賺取下跌的價差。 | 一般定義 |
| **多空組合** | 同時買進預測會漲的股票、放空預測會跌的股票，賺兩者之間的相對差距，降低大盤漲跌的影響。 | 一般定義 |
| **bps（基點）** | 1 bp = 0.01%，100 bps = 1%。常用來表示很小的報酬或交易成本。 | 一般定義 |
| **最大回撤** | 投資期間內，資產從最高點跌到之後最低點的最大跌幅。 | 一般定義 |
| **換手率** | 一段期間內買賣的金額占投資組合的比例；越高代表越頻繁換股，交易成本也越高。 | 一般定義 |
| **樣外測試 (out-of-sample)** | 用模型訓練時「沒看過」的新資料來檢驗預測力，避免拿背過答案的題目考自己。 | [[2020_RFS_Gu_Kelly_Xiu_Empirical_Asset_Pricing_via_Machine_Learning]] |
| **過擬合 (overfitting)** | 模型把歷史資料裡的隨機雜訊也當成規律記下來，在新資料上反而表現變差。 | [[機器學習資產定價]] |
| **訊噪比** | 有用的訊號相對於隨機雜訊的強弱。股價資料雜訊很多、訊號很弱，所以訊噪比很低。 | [[機器學習資產定價]] |
| **市值加權 vs 等權** | 市值加權：依公司市值大小分配資金（大公司權重高）；等權：每檔股票投入相同金額。 | 一般定義 |
| **積極單 vs 被動單** | 積極單：買價高於或等於當時最低賣價（或賣價低於或等於最高買價），會立即成交；被動單：掛在市場上等別人來成交。 | [[2009_RFS_Barber_Lee_Liu_Odean_Just_How_Much_Do_Individual_Investors_Lose_by_Trading]] |
| **因子** | 能用來解釋或預測股票報酬差異的共同特徵，例如公司大小、過去漲跌、便宜或昂貴。 | 一般定義 |
| **動能** | 過去一段時間（例如 12 個月）漲得多的股票，接下來傾向繼續相對強勢的現象。 | 一般定義；GKX 的 `mom12m` 即 12 個月動能 |
| **流動性** | 股票能否快速、低成本買賣；成交量大、買賣價差小代表流動性好。 | 一般定義 |
| **R²（樣外 R²）** | 預測解釋了多少實際報酬的變動；學術上以「預測為 0」當基準，負值代表比直接猜 0 還差。 | [[機器學習資產定價]] |
| **漂移（反應不足）** | 新聞公開後，股價沒有一次反應完，而是在之後一段時間繼續往同方向慢慢走。 | [[2026_JFE_Lopez-Lira_Tang_Can_ChatGPT_Forecast_Stock_Price_Movements]] |
| **損失函數** | 訓練模型時用來衡量「預測錯多少」的公式；模型會設法讓它變小。均方誤差 (MSE) 是最常見的一種。 | 一般定義 |
| **法人／外資** | 法人指機構投資人，例如企業、自營商、外資、國內投信基金；外資是外國機構投資人。 | [[2009_RFS_Barber_Lee_Liu_Odean_Just_How_Much_Do_Individual_Investors_Lose_by_Trading]] |
| **衝擊成本** | 下單時因為主動吃掉對方掛單、推動價格，而多付出的隱形成本。 | 一般定義 |
| **逆向挑選** | 掛單等人成交時，常常是「知道更多的人」才來成交，掛單者因此長期吃虧。 | [[2009_RFS_Barber_Lee_Liu_Odean_Just_How_Much_Do_Individual_Investors_Lose_by_Trading]] |
